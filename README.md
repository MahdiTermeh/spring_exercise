# Spring Boot & Thymeleaf Fundamentals 🚀

This repository is part of my ongoing journey to master **Java Spring Boot** and server-side rendering with **Thymeleaf**. The main goal of this project is to practice handling HTTP requests, passing data through the `Model` object, and rendering dynamic content in HTML views.

## 🎯 Learning Objectives
In this specific exercise, I focused on:
- **MVC Pattern:** Understanding the flow between Controller, Model, and View.
- **Request Mapping:** Using `@GetMapping` and `@RequestMapping` to handle different URL patterns.
- **Dynamic Templating:** Using Thymeleaf attributes (like `th:text` and expression language `${...}`) to display data passed from the backend.
- **Form Data Handling:** Capturing user input via `@RequestParam`.

## 🛠️ Technologies Used
- **Java** (JDK 17+)
- **Spring Boot** (Web Starter)
- **Thymeleaf** (Template Engine)
- **Maven** (Build Tool)
